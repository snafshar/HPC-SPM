# Speedup and Parallel Efficiency

For serial runtime T1 and parallel runtime Tp, speedup is S_p=T1/Tp and efficiency is E_p=S_p/p. Measure the same workload and include startup, communication, synchronization, and I/O consistently.

Amdahl's law explains how a serial fraction limits speedup. Weak scaling asks a different question from strong scaling; state which experiment is being performed.
